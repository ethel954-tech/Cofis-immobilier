# Modules métier

Chaque domaine fonctionnel sera isolé dans son propre module :

- proprietaires
- immeubles
- unites
- locataires
- baux
- echeances
- paiements
- impayes
- depenses
- reversements
- rapports
- utilisateurs
- parametres

Chaque module pourra contenir ses composants, services, schémas de validation et types.

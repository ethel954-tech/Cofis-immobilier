# Bibliothèque applicative

Les utilitaires partagés seront organisés ici :

- `supabase/` : clients Supabase navigateur et serveur, après validation de l'environnement.
- `autorisations/` : contrôle des rôles et périmètres d'accès.
- `validations/` : schémas Zod et règles de validation.
- `formatage/` : formatage des montants FCFA, dates et libellés.

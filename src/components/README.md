# Composants partagés

- `layout/` : cadres de page et structures générales.
- `navigation/` : navigation latérale et en-tête.
- Les composants de formulaire, tableaux, fenêtres modales et indicateurs seront ajoutés au rythme des modules métier.

Les composants de navigation non encore développés restent visuellement désactivés : ils ne doivent pas suggérer qu'une fonctionnalité est déjà opérationnelle.
